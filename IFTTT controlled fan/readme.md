
Purpose
To use our IFTTT controlled fan, create Fan Speed 1-9 IFTTT applets in your account accordingly.
This Applet sets the fan to Speed 1-9 (Low-High) through IFTTT. It can be triggered manually or by another automation workflow to ensure the fan always switches to a predefined speed level.

For example, for Fan Speed 1

Before creating the Applet, make sure:

You have an IFTTT account.
The fan service is connected to IFTTT.
The fan can be controlled through an available "Set Fan Speed" action.
Create the Applet
Step 1. Create a new Applet
Go to:
https://ifttt.com/create

Then select Create.

Step 2. Configure the Trigger with webrequest: "fan_speed_1"


Step 3. Configure the Action
Click Add under Then That.
Select the fan service.
Choose Set Fan Speed.
Set the speed value to:
1

(or Low, depending on the service interface).

Step 4. Save and Enable
Click Continue.
Give the Applet a name:
Fan Speed 1
Click Finish.
Turn the Applet on.
